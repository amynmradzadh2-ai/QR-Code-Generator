## 🇬🇧 English

### ✨ About The Project

QR Code Generator is a Python-based application designed to create QR codes quickly and easily.

With this tool, you can generate QR codes for text, website URLs, contact information, and Wi-Fi networks.

A simple and practical project built to improve Python programming skills and explore real-world applications.

### 🌟 Features

- 🔗 **Text & URL:** Generate QR codes from text and website links.
- 👤 **Contact Card:** Create digital contact cards using vCard 3.0.
- 📶 **Wi-Fi QR:** Generate QR codes for wireless networks.
- 🔐 **Security Support:** Supports WPA, WEP, and open networks.
- 💾 **Automatic Saving:** Save generated QR codes as PNG images.
- 📁 **File Management:** Automatically creates an output directory.
- 🛡️ **Error Handling:** Validates inputs and handles common errors.
- 🕒 **Unique Filenames:** Uses timestamps to prevent filename conflicts.

### 🛠️ Technologies

- 🐍 Python
- 📦 QRCode
- 🖼️ Pillow

### ⚙️ Installation & Usage

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd QR-Code-Generator
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python main.py
```
